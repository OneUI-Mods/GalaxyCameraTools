# Galaxy Camera Tools 0.1.2 実験版

写真・動画のレンズ切り替えに、少しゆっくりした加減速を加えました。スーパー手ブレ補正・水平ロックでも切り替えの動きを追加し、Expert RAWも同じ時間調整を使います。

純正カメラの「レンズ切り替えを滑らかにする」を、写真プレビューの60fps設定から分離しました。更新時は以前のON状態を一度だけ引き継ぎ、その後は個別に変更できます。Camera Assistantからも設定できます。

カメラ使用中の追加処理を整理し、未処理のズーム更新をため込まないようにしました。「写真プレビューを軽くする」をONにすると、対応する背面写真のプレビュー解像度を下げて映像の負荷を抑えられます。プレビューの精細さは下がりますが、保存する写真・動画の解像度は維持します。カメラを開き直すと反映されます。

写真プレビューの60fpsの適用処理も見直しました。ただし、5倍側や戻る操作などで実映像が30fpsになる経路はまだ残っており、引き続き調査が必要です。温度保護が働く場合は純正のfpsへ戻します。手ブレ補正・水平ロックで使える解像度や録画fpsも純正の条件に従います。

対応環境はGalaxy S26 Ultra（SM-S948Q）、Android 17 / One UI 9 BZI9、Samsung Camera 17.0.00.43、Camera Assistant 5.0.00.7、Expert RAW 6.0.02.8です。rootとAPI 102対応Vectorが必要です。

署名済みrelease APKで更新後、撮影・録画を終了し、Samsungカメラ・Expert RAW・Camera Assistantを強制停止して開き直してください。純正カメラを一度開いてからExpert RAWを使用します。設定は引き継ぎます。今回の更新を反映するための端末・SystemUIの再起動は不要です。
