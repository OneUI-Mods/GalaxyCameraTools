# Galaxy Camera Tools 0.1.3 実験版

写真のレンズ切り替えで映像が30fpsになる場面でも、拡大・縮小の動きを60fpsで描画する表示処理を追加しました。これまでの、少しゆっくりした加減速は維持します。

「写真プレビューを60fpsにする」と「レンズ切り替えを滑らかにする」を両方ONにすると、対応する背面写真で使えます。直前の映像を一時的に拡大・縮小し、新しいレンズの映像へつなぎます。縮小時の境界もなじませました。取得できない場合や高温時は従来の切り替えへ戻ります。

**撮像そのものの全経路60fpsを達成した更新ではありません。** 5倍や超広角などで実映像が30fpsになる場合は残っています。また切り替え中は直前の映像を使うため、動く被写体が短く止まって見えたり、新しい映像との露出差が見えたりする場合があります。保存写真の解像度は維持します。

対応環境はGalaxy S26 Ultra（SM-S948Q）、Android 17 / One UI 9 BZI9、Samsung Camera 17.0.00.43です。Camera Assistant 5.0.00.7、Expert RAW 6.0.02.8への従来の対応も維持します。rootとAPI 102対応Vectorが必要です。

署名済みrelease APKで更新後、撮影・録画を終了し、SamsungカメラとCamera Assistantを強制停止して開き直してください。設定は引き継ぎます。今回の写真表示の変更に端末本体やSystemUIの再起動は不要です。
