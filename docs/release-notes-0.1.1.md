# Galaxy Camera Tools 0.1.1 実験版

通常写真とExpert RAWのレンズ切り替えを改善しました。純正カメラでは、ズームのイージングを画面の描画に同期させ、処理が遅れたときも古いズーム値を連続送信せず、現在の位置へ追従します。「写真プレビューを60fpsにする」をONにすると適用されます。

Expert RAWでは、ぼかしとフェードだけだった切り替えに画角の拡大・縮小を追加しました。純正カメラから取得したズームカーブと所要時間を使い、新レンズの映像へつなぎます。「レンズの切り替えを滑らかにする」でON／OFFできます。連続した選択では最後に選んだレンズへ進み、画面を閉じた場合やOFFにした場合は表示を元に戻します。

対応環境はGalaxy S26 Ultra（SM-S948Q）、Android 17 / One UI 9 BZI9、Samsung Camera 17.0.00.43、Camera Assistant 5.0.00.7、Expert RAW 6.0.02.8です。rootとAPI 102対応Vectorが必要です。

署名済みrelease APKで更新後、撮影・録画を終えてSamsungカメラとExpert RAWを強制停止してください。純正カメラを一度開いてからExpert RAWを使用します。0.1.0からこの更新を反映するための端末再起動は不要です。設定は引き継ぎます。

実際のプレビューfpsはレンズ、明るさ、温度、カメラ側の処理に依存します。画面のアニメーションが滑らかになることと、すべての撮影条件で映像が60fpsになることは別です。Expert RAWのレンズ準備に時間がかかる場合は、切り替え完了までの時間も純正カメラと異なる場合があります。保存する写真の画角やRAWの撮影設定は変更しません。
