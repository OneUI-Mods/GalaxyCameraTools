# Reliability audit — 2026-11-18

## 設定取得の再試行回数が生涯累積される

The settings retry count did not reset on success. Independent short outages eventually exhausted the lifetime allowance. Use an episode-scoped finite backoff budget, coalesce pending retries, and serialize settings loads. Regression tests cover repeated successful recoveries and exhaustion.

No feature switches, boot preferences, signing identity, target scopes or Android 16/17 compatibility gates are changed. This is a source fix and regression check, not proof of physical-device behavior. No release APK is distributed by this audit.
