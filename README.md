# Galaxy Camera Tools

Samsung Camera・Camera Assistant・Expert RAWを拡張する、実験的なVectorモジュールです。機能は個別にON／OFFでき、専用アプリとCamera Assistantの設定が連動します。

## できること

| 機能 | 内容 |
| --- | --- |
| 写真のプレビュー | 対応する通常写真プレビューへ60fpsを要求し、レンズ切り替えを描画に同期してイージング |
| 通常動画の120fps | 背面FHD・UHDの対応する録画設定を通常の動画モードへ追加 |
| 超広角のライト | 背面超広角でも純正のフラッシュ・動画ライトを使用 |
| フラッシュ中のピント固定 | 発光前のピント位置を保持し、撮影後・キャンセル時にAFへ復帰 |
| クイックパネルのライト | 背面カメラの写真・通常動画の使用中にもライトを操作 |
| Expert RAWのレンズ切り替え | 純正カメラのズームカーブと時間に合わせ、画角の拡大・縮小から新しい映像へつなぐ |
| 一般アプリのCamera2 | 対応するアプリから背面の追加レンズを選択 |

## 対応環境

初期実験版の対象はGalaxy S26 Ultra（SM-S948Q）、Android 17 / One UI 9 BZI9です。Samsung Camera 17.0.00.43、Camera Assistant 5.0.00.7、Expert RAW 6.0.02.8を対象にしています。対応するroot環境とlibxposed API 102対応Vectorが必要です。

別の端末・ファームウェア・対象アプリの版へ、未確認の撮影処理を適用しません。Android 16向けの既存アプリや互換処理を置き換える更新ではありません。

## 導入・使い方

1. [Releases](https://github.com/OneUI-Mods/GalaxyCameraTools/releases)から署名済みrelease APKをインストールします。
2. VectorでGalaxy Camera Toolsを有効にし、使う機能に応じて下表の対象を選びます。
3. 導入・APK更新後は対象アプリを強制停止して開き直します。SystemUIは初回の有効化・更新後に再読み込みしてください。[Galaxy Reload](https://github.com/OneUI-Mods/galaxy-reload)も利用できます。
4. 専用アプリ、またはCamera Assistantで必要なスイッチをONにします。初期値はすべてOFFです。

| 使う機能 | Vectorで選ぶ対象 |
| --- | --- |
| 写真・動画・超広角ライト・ピント固定 | Samsungカメラ |
| Camera Assistant内の追加設定 | Camera Assistant |
| RAWのレンズ切り替え | Expert RAW |
| クイックパネルのライト | SamsungカメラとSystemUI |
| 一般アプリの追加レンズ | 利用するカメラアプリを個別に追加 |

更新後は純正カメラを一度開いてからExpert RAWを使用してください。レンズ切り替えの設定は、通常写真では「写真プレビューを60fpsにする」、Expert RAWでは「レンズの切り替えを滑らかにする」で切り替えます。

Camera2の追加レンズは、対象アプリへカメラ権限を許可してから開き直してください。初回に選択肢が出ない場合は、もう一度開き直します。設定を変更した後も、使用中のカメラを閉じて開き直すと反映されます。アプリ側にレンズ選択機能がない場合は選べません。

## 制限・使う前の確認

- 120fpsは背面FHD・UHDの対応する16:9設定が対象です。8K・HD・前面・特殊な縦横比には追加しません。音声付きの保存動画を確認していますが、長時間録画の上限や発熱は純正・端末の条件に依存します。
- 写真プレビューの60fpsは対応する映像サイズに限ります。前面カメラや背面レンズの切り替え中など、30fpsになる場合があります。暗所・温度・カメラ側の処理でも実際のfpsは変わります。
- ピント固定では発光前の位置を使います。被写体が動いた場合は撮影前に合わせ直してください。通常時のAFは維持します。
- クイックパネルのライトは背面の写真・通常動画向けです。カメラを離れると、この機能で点灯したライトを消します。温度・電池残量などの純正の保護は維持します。
- 一般アプリの追加レンズは標準Camera2に対応する撮影方式が対象です。メイン・3倍・5倍のプレビューと、追加の望遠レンズのJPEG撮影を確認しています。すべてのアプリ、RAW、特殊なセッション、高解像度・高fpsの組み合わせを確認済みとするものではありません。非対応の解像度やfpsを作る機能ではなく、カメラ権限も必要です。
- Expert RAWでプレビューを取得できない場合は待ち続けず、通常のレンズ切り替えへ戻ります。

大切な撮影の前には、短い撮影で映像・音声と必要な機能を確認してください。

## 停止・復旧

該当機能のスイッチをOFFにし、対象アプリを開き直します。完全に外す場合はVectorで無効にして対象プロセスを再読み込みしてください。

モジュールの操作後に短時間で異常終了を繰り返した場合は、そのアプリへの変更を停止します。原因を解消してから「状態・情報」で保護を解除し、対象アプリを開き直して再試行できます。
